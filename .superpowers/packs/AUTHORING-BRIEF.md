# Как писать паки для «Свояка»

Ты пишешь вопросы для домашней «Своей игры». Ведущий читает вопрос вслух с
ноутбука, гости отвечают голосом, жмякая кнопку на телефоне. Публика —
русскоязычные жители Казахстана, компания друзей за столом, 2026 год.

## Единственное правило, из-за которого всё это переписывается

**Вопрос обязан работать, если его просто прочитать вслух.**

Предыдущие паки распарсили с ютуба, и 262 вопроса из 389 повторяли текст
соседа: «Назовите знак зодиака по его символу» пять раз подряд, потому что
настоящий вопрос был картинкой на экране. 73 из них остались вообще без
картинки — ведущему нечего было показать. Играть в это невозможно.

Отсюда:

- Никаких двух вопросов с одинаковым текстом в одном паке.
- Никаких «на экране», «на картинке», «по символу», «послушайте» — если
  только к вопросу реально не приложено медиа (а ты медиа не прикладываешь,
  см. ниже).
- Каждый вопрос самодостаточен: в нём есть всё, чтобы на него ответить.

Автоматическая проверка `server/src/packs/packs.lint.test.ts` ловит это
механически. Она запускается в общем прогоне тестов, и пак, который её не
проходит, в игру не попадёт.

## Тон

Ориентир — выпуски «СВОЯКа» Димы Коваля: живо, конкретно, с подначкой. Не
энциклопедия. Вопрос должен быть интересно услышать, даже если не знаешь
ответа.

**Хорошо:**
> Какой напиток из кобыльего молока в Казахстане пьют холодным, а туристы
> обычно морщатся с первого глотка? → Кумыс

**Плохо (сухо, читается как учебник):**
> Как называется кисломолочный напиток из кобыльего молока? → Кумыс

**Хорошо (современно, с характером):**
> Этот казахстанский певец берёт ноты, от которых у жюри выпадают челюсти,
> а диапазон ему меряли отдельной статьёй в Википедии. → Димаш Кудайберген

**Плохо (википедийная справка):**
> Какой казахстанский певец известен широким вокальным диапазоном? → Димаш

Пиши **современно**: 2020-е, а не 1990-е. Актуальная музыка, сериалы,
мемы, Казнет, доставки, маркетплейсы, тикток-феномены, новые здания и
новые имена — вперемешку с тем, что знают все.

## Формат пака

Один файл — один пак. Структура жёсткая, проверка её сверяет:

- **2 раунда по 4 темы, в каждой теме 5 вопросов.** Итого 40.
- Цены: первый раунд `100 200 300 400 500`, второй `200 400 600 800 1000`.
  Строго в этом порядке внутри темы.
- **Ровно один вопрос типа `cat`** (кот в мешке) и **ровно один `auction`**
  (аукцион) на весь пак. Оба — во втором раунде, на дорогих клетках.
- **3 темы в финале**, в каждой ровно один вопрос.
- Сложность растёт с ценой. За 100 отвечает любой, за 500 — тот, кто в теме.

### JSON

```json
{
  "id": "pack-<slug>",
  "title": "Человеческое название",
  "author": "Свояк",
  "description": "Одна строка: о чём пак.",
  "createdAt": 1790000000000,
  "updatedAt": 1790000000000,
  "rounds": [
    {
      "id": "pack-<slug>-r1",
      "title": "Первый раунд",
      "themes": [
        {
          "id": "pack-<slug>-r1-t1",
          "title": "Название темы",
          "comment": "Необязательная подсказка ведущему про тему",
          "questions": [
            {
              "id": "pack-<slug>-r1-t1-q1",
              "price": 100,
              "type": "normal",
              "text": "Текст вопроса.",
              "answer": "Ответ",
              "altAnswers": ["Другой приемлемый вариант"]
            }
          ]
        }
      ]
    }
  ],
  "final": {
    "themes": [
      {
        "id": "pack-<slug>-f1",
        "title": "Тема финала",
        "question": {
          "id": "pack-<slug>-f1-q",
          "text": "Текст.",
          "answer": "Ответ",
          "altAnswers": []
        }
      }
    ]
  }
}
```

Кот в мешке дополнительно требует поле `cat`:

```json
{
  "id": "...", "price": 600, "type": "cat",
  "text": "...", "answer": "...", "altAnswers": [],
  "cat": { "theme": "Тема кота", "price": "nominal", "canKeep": false }
}
```

`cat.theme` объявляют вслух до передачи, поэтому она должна намекать на
содержание, но не выдавать ответ.

`hostComment` — необязательное поле, его видит только ведущий. Годится,
чтобы дать ему право засчитать неточный ответ: `"Засчитывай и «Алма-Ата»."`

### altAnswers

Заполняй щедро — примерно у двух третей вопросов. Это варианты, которые
ведущий обязан засчитать: «Алма-Ата» к «Алматы», фамилия без имени,
разговорное название, другой падеж по смыслу. Без них ведущий спорит с
гостями вместо того, чтобы вести игру.

## Медиа

**Не добавляй поля `media` и `answerMedia`.** Ты не можешь положить файл на
диск, а ссылка на несуществующую картинку — ровно та поломка, из-за которой
старые паки выбросили. Проверка это поймает.

Если картинка реально напрашивается — напиши это в `hostComment`:
`"Сюда хорошо бы фото здания."` Человек потом прикрепит в редакторе.

**Эмодзи — это текст, а не медиа.** Ребусы из эмодзи работают прекрасно и
ничего не требуют:

> 🐎 + 🥛 = что пьют на тое? → Кумыс

Такие темы очень приветствуются: они современные и смешные.

## Достоверность

Скучный правдивый вопрос лучше смешного неверного. Не выдумывай даты,
рекорды, статистику и «первый в мире». Если не уверен — выбери формулировку,
которая остаётся верной: не «сколько именно», а «больше или меньше».

В отчёте перечисли вопросы, в которых ты менее уверен, — их перепроверит
человек.

## Язык

Всё по-русски. Казахские слова — кириллицей, как их пишут в русском тексте
Казахстана (бешбармак, шанырак, той, дастархан, акын). Букву «ё» пиши.
