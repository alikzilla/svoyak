# Свояк

Своя игра для домашней компании: ведущий за ноутбуком, игроки — со своих
телефонов. Вся логика на сервере, телефон нужен только чтобы жать кнопку
и вводить ответы в финале.

## Быстрый старт

```bash
npm install
npm run build:packs   # разложить демо-паки в data/packs
npm run dev           # сервер :3001 и клиент :5173
```

При старте в консоль печатается ссылка для игроков и QR-код — наведите на
него камеру телефона, подключённого к той же Wi-Fi сети.

| Экран       | Адрес                          |
| ----------- | ------------------------------ |
| Ведущий     | `http://localhost:5173/host`   |
| Игрок       | `http://<ваш-IP>:5173/join`    |
| Общий экран | `http://localhost:5173/board`  |
| Редактор    | `http://localhost:5173/editor` |

Общий экран стоит вывести на телевизор: на нём табло, вопрос и счёт без
управления.

## Как играть

1. Ведущий открывает `/host`, выбирает пак — появляются код комнаты и QR.
2. Гости наводят камеру на QR и вводят имя. Код подставляется сам.
3. Ведущий жмёт «Начать игру». Право хода получает первый вошедший.
4. Чей ход — тот называет тему и цену вслух, а открывает вопрос ведущий.
   На телефоне этого игрока показано табло, но только для чтения.
5. Ведущий читает вопрос и сам жмёт «Открыть кнопку»: темп задаёт он, а
   не таймер. Нажатие до открытия — фальстарт, блокировка на пару секунд.
6. Кто нажал первым, отвечает вслух. Ведущий решает, когда времени было
   достаточно, и жмёт «Верно» или «Неверно».
7. Неверный ответ снимает стоимость вопроса, и кнопка открывается
   остальным. Время, потраченное на чужой устный ответ, из их окна не
   вычитается. Вопрос закрывается, только когда ошиблись все или когда
   при открытой кнопке никто не нажал.

Ведущий в любой момент может поправить счёт, передать право хода,
поставить паузу, снять вопрос, добавить времени на кнопку и отменить
последнее действие.

### Кнопка честная

Клиент раз в две секунды измеряет задержку до сервера и шлёт нажатие со
своей меткой времени. Сервер переводит метку в своё время, отбрасывает
неправдоподобные значения и, получив первое нажатие, ждёт ещё 150 мс,
чтобы собрать остальные. Побеждает самая ранняя метка, а не самый быстрый
интернет.

### Спецвопросы

**Кот в мешке** передаётся другому игроку. Открывший видит только тему
кота и его стоимость — текст вопроса скрыт от всех игроков, чтобы кота
нельзя было отдать «с умыслом». Отвечает только получивший, кнопка не
работает. Верно — деньги и право хода ему; неверно — минус ему, а право
хода остаётся у передавшего.

**Аукцион** разыгрывается вслепую: игроки видят тему и цену, но не
вопрос. Номинал ставит открывший, дальше по кругу можно поднять минимум
на шаг, уйти ва-банк или спасовать. Пас необратим, а тому, кому нечем
перебить, ход не предлагается. Победитель играет один, и счёт меняется на
его ставку, а не на номинал.

### Финал

В финал проходят игроки с положительным счётом — это отключается
настройкой. Дальше:

1. Игроки по очереди, начиная с того, у кого меньше очков, убирают темы,
   пока не останется одна.
2. Каждый втайне ставит от 1 до своего счёта. Вопрос в этот момент ещё не
   показывают: ставят, зная только тему.
3. Появляется вопрос, каждый пишет ответ текстом.
4. Ведущий вскрывает ответы по одному, от меньшего счёта к большему, и
   судит. Чужую ставку и чужой ответ до вскрытия не видит никто.

Если кто-то отвалился и держит всех, ведущий жмёт «Не ждать отставших» —
недостающие ставки считаются минимальными.

## Свои вопросы

Редактор живёт на `/editor` и работает без запущенной игры.

- **Быстрая вставка темы.** Кнопка «Вставить тему текстом» принимает
  строки вида `цена | вопрос | ответ`; четвёртая колонка — другие
  принимаемые ответы через точку с запятой. Перед добавлением показывается
  разбор и строки с ошибками.

  ```
  Тема: Кино
  100 | Кто снял «Крёстного отца»? | Фрэнсис Форд Коппола | Коппола
  200 | Какого цвета таблетку глотает Нео? | Красную
  ```

- **Медиа.** К вопросу и к ответу можно приложить картинку, аудио или
  видео до 50 МБ — файлы лежат в `uploads/<пак>/`.
- **Спецвопросы.** Тип выбирается в форме: обычный, кот в мешке (с темой
  и своей стоимостью) или аукцион.
- **Порядок.** Темы и вопросы перетаскиваются за значок слева.
- **Экспорт и импорт.** «Скачать JSON» сохраняет пак файлом, «Импорт
  JSON» загружает его обратно как новый пак.
- **Паки из SIGame.** «Импорт .siq» принимает архивы из сети: разбираются
  обе распространённые версии формата, переносятся типы вопросов, медиа
  из архива и комментарии к ответу. Формат менялся годами, поэтому после
  импорта показывается **отчёт**: что перенеслось, какие файлы не нашлись
  и какие вопросы нужно поправить руками. Молча ничего не теряется.

Недоделанный пак сохраняется свободно — правка идёт постепенно. Но пока в
проверке есть ошибки (пустой вопрос или ответ), создать комнату на этом
паке нельзя.

## Игра на расстоянии

Если друзья не в вашей квартире, поднимите туннель к клиенту (порт 5173) —
запросы к серверу пойдут через тот же адрес.

**Cloudflare Tunnel** (не требует регистрации):

```bash
brew install cloudflared          # или скачайте с сайта Cloudflare
cloudflared tunnel --url http://localhost:5173
```

Команда напечатает адрес вида `https://random-words.trycloudflare.com`.

**ngrok:**

```bash
ngrok http 5173
```

Дальше перезапустите игру, передав внешний адрес, — тогда ссылка и QR на
экране ведущего будут вести туда, а не в вашу локальную сеть:

```bash
PUBLIC_URL=https://random-words.trycloudflare.com npm run dev
```

Домены `trycloudflare.com`, `ngrok-free.app`, `ngrok.io` и `loca.lt`
разрешены заранее. Для другого туннеля добавьте его домен:

```bash
ALLOWED_HOSTS=.example.com PUBLIC_URL=https://tunnel.example.com npm run dev
```

Учтите: туннель открывает игру всем, у кого есть ссылка. Комната защищена
только кодом, так что не публикуйте адрес там, где его увидят посторонние.

## Настройки комнаты

Задаются при создании комнаты, значения по умолчанию — в
`shared/src/settings.ts`:

| Настройка              | По умолчанию | Что делает                                    |
| ---------------------- | ------------ | --------------------------------------------- |
| `buzzOpenMs`           | 8000         | сколько всего кнопка открыта на вопрос         |
| `buzzGraceMs`          | 150          | окно сбора нажатий                             |
| `buzzReopenMinMs`      | 3000         | минимум времени остальным после чужой ошибки   |
| `falseStartLockMs`     | 2500         | блокировка за фальстарт                        |
| `penaltyOnWrong`       | да           | снимать ли стоимость за неверный ответ         |
| `allowNegative`        | да           | разрешать ли уходить в минус                   |
| `finalRequiresPositive`| да           | пускать в финал только с положительным счётом  |
| `auctionStep`          | 100          | минимальный шаг повышения ставки               |

Таймеров на чтение вопроса и на устный ответ нет: темп игры задаёт
ведущий.

## Внешний вид и звук

Игра нарисована «маркером»: толстые чёрные обводки, жёсткие смещённые
тени, кривоватые рамки на Rough.js и плывущие каракули на индиговом фоне.
Страница `/style` — живой стиль-гид: там собраны палитра, шрифты,
кнопки, аватары, таймер и спецсцены, и всё это можно потрогать.

**Персонаж игрока** собирается из его имени — форма головы, глаза, рот,
причёска и цвет. У человека он один и тот же на всех экранах, и его же
цвет ходит за ним в счёте, рамках и конфетти.

**Звуки** не скачиваются, а синтезируются скриптом в WAV — ни внешних
сервисов, ни вопросов с лицензиями, работает без интернета:

```bash
node client/scripts/makeSounds.mjs   # пересобрать сэмплы в client/public/sounds
```

Шрифты (Unbounded и Rubik) тоже подключены локально через npm, а не с
Google Fonts — по той же причине.

**Спокойный режим.** Игра уважает системную настройку «уменьшить
движение», а на странице стиля есть переключатель, оставляющий только
затухания, и тумблер плотности фоновых каракулей — на случай слабого
ноутбука или стрима.

## Полезные команды

```bash
npm test          # тесты игровой логики
npm run typecheck
npm run build:packs
node client/scripts/makeSounds.mjs
```

Служебный скрипт для проверки поздних стадий игры без разыгрывания
партии: поднимает комнату с двумя игроками (токены `seed-a`, `seed-b`,
ведущий `seed-host-token`).

```bash
npx tsx --tsconfig server/tsconfig.json server/src/packs/seedRoom.ts 7777 round2
npx tsx --tsconfig server/tsconfig.json server/src/packs/seedRoom.ts 5555 final
```

## Как устроено

```
shared/   типы пака, состояния комнаты и сокет-событий, валидация
server/   игровой движок, комнаты, хранилище, импорт паков
client/   экраны ведущего, игрока, табло и редактора
data/     паки, автосохранения комнат
uploads/  медиа вопросов
docs/     дизайн-документ и планы реализации
```

Игровая логика — чистый редьюсер: `reduce(state, action) → {state,
effects}`, без сети и таймеров внутри. Таймеры и рассылка живут снаружи,
поэтому правила тестируются без сокетов, отмена действия — это снимок
состояния, а автосохранение — сериализация после каждого действия.

Клиенту уходит не состояние комнаты, а **проекция его роли**. Правильный
ответ, комментарии ведущего и чужие ставки физически не попадают в данные
игрока — на это стоят тесты, которые ищут ответ в сериализованной
проекции.

Комната переживает перезагрузку страницы у любого участника и перезапуск
сервера: игрок возвращается по токену из `localStorage`, а если тот
потерян — по имени, вместе со своим счётом.

## Если что-то не работает

**Телефон не открывает страницу.** Проверьте, что он в той же сети, а не
в мобильном интернете. Некоторые роутеры включают изоляцию клиентов —
тогда поможет только туннель. На macOS может мешать файрвол: разрешите
входящие подключения для Node.

**Игрок вышел и не может вернуться.** Пусть зайдёт заново по коду с тем же
именем — счёт вернётся.

**Звука нет.** Браузеры не дают играть звук до первого касания экрана:
нажмите что-нибудь. Выключатель звука есть на экранах ведущего и игрока,
и выбор запоминается.

**Проверяете с одного компьютера.** Вкладки ведущего и игроков делят
`localStorage` и перетирают друг другу сессию. Откройте роли на разных
адресах — `localhost`, `127.0.0.1` и адрес в локальной сети: для браузера
это разные хранилища.
