# Свояк

Своя игра для домашней компании: ведущий за ноутбуком, игроки — с телефонов.

> Проект в разработке. Готово: комнаты, подключение с телефонов, полный
> игровой цикл обычными вопросами и редактор паков. Впереди спецвопросы
> (кот в мешке, аукцион), финал и импорт .siq.

## Запуск

```bash
npm install
npm run build:packs   # разложить демо-паки в data/packs
npm run dev           # сервер :3001 и клиент :5173
```

При старте сервер печатает в консоль ссылку для игроков и QR-код —
наведите на него камеру телефона в той же Wi-Fi сети.

| Экран        | Адрес                        |
| ------------ | ---------------------------- |
| Ведущий      | `http://localhost:5173/host` |
| Игрок        | `http://<ваш-IP>:5173/join`  |
| Общий экран  | `http://localhost:5173/board`|
| Редактор     | `http://localhost:5173/editor` |

## Как играть

1. Ведущий открывает `/host`, выбирает пак — появляется код комнаты и QR.
2. Друзья наводят камеру на QR и вводят имя.
3. Ведущий жмёт «Начать игру». Право хода получает первый вошедший.
4. Чей ход — тот называет тему и цену вслух, а открывает вопрос ведущий.
   На телефоне этого игрока показывается табло, но только для чтения:
   кликать по клеткам могут только с экрана ведущего.
5. Ведущий открывает вопрос, читает вслух и сам жмёт «Открыть кнопку» —
   темп задаёт он, а не таймер. Нажатие до открытия кнопки — фальстарт,
   блокировка на пару секунд.
6. Ведущий жмёт «Верно» или «Неверно». Времени на устный ответ не
   отмеряется: ведущий сам решает, когда его было достаточно.
7. После неверного ответа игрок теряет стоимость вопроса и выбывает из
   него, а кнопка открывается остальным. Время, потраченное на устный
   ответ, из их окна не вычитается, и окно не короче трёх секунд.
   Вопрос закрывается, только когда ошиблись все или когда при открытой
   кнопке никто не нажал.

Всё время игры ведущий может поправить счёт, передать право хода,
поставить паузу, снять вопрос, добавить времени и отменить последнее
действие.

## Свои вопросы

Редактор живёт на `/editor` и работает без запущенной игры.

- **Быстрая вставка темы.** Кнопка «Вставить тему текстом» принимает
  список строк вида `цена | вопрос | ответ`; четвёртая колонка —
  другие принимаемые ответы через точку с запятой. Перед добавлением
  показывается разбор и строки с ошибками.
- **Медиа.** К вопросу и к ответу можно приложить картинку, аудио или
  видео до 50 МБ — файлы лежат в `uploads/<пак>/`.
- **Спецвопросы.** Тип вопроса выбирается в форме: обычный, кот в мешке
  (с темой и своей стоимостью) или аукцион.
- **Порядок.** Темы и вопросы перетаскиваются за значок слева.
- **Экспорт и импорт.** «Скачать JSON» сохраняет пак файлом, «Импорт
  JSON» на списке паков загружает его обратно как новый пак.

Недоделанный пак сохраняется свободно — правка идёт постепенно. Но пока
в проверке есть ошибки (пустой вопрос или ответ), создать комнату на
этом паке нельзя.

## Структура

```
shared/   типы пака, состояния комнаты и сокет-событий
server/   игровая логика, комнаты, хранилище, импорт паков
client/   React-интерфейсы ведущего, игрока, табло и редактора
data/     паки, автосохранения комнат, история игр
uploads/  медиа вопросов
docs/     дизайн-документ и планы реализации
```
