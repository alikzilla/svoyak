# Свояк

Своя игра для домашней компании: ведущий за ноутбуком, игроки — с телефонов.

> Проект в разработке. Готово: комнаты, подключение с телефонов и полный
> игровой цикл обычными вопросами. Впереди редактор паков, спецвопросы,
> финал и импорт .siq.

## Запуск

```bash
npm install
npm run build:packs   # разложить демо-паки в data/packs
npm run dev           # сервер :3001 и клиент :5173
```

При старте сервер печатает в консоль ссылку для игроков и QR-код —
наведите на него камеру телефона в той же Wi-Fi сети.

| Экран        | Адрес                        |
| ------------ | ---------------------------- |
| Ведущий      | `http://localhost:5173/host` |
| Игрок        | `http://<ваш-IP>:5173/join`  |
| Общий экран  | `http://localhost:5173/board`|
| Редактор     | `http://localhost:5173/editor` |

## Как играть

1. Ведущий открывает `/host`, выбирает пак — появляется код комнаты и QR.
2. Друзья наводят камеру на QR и вводят имя.
3. Ведущий жмёт «Начать игру». Право хода получает первый вошедший.
4. Чей ход — тот называет тему и цену вслух, а открывает вопрос ведущий.
   На телефоне этого игрока показывается табло, но только для чтения:
   кликать по клеткам могут только с экрана ведущего.
5. Вопрос читается несколько секунд, затем кнопка открывается сама.
   Нажатие до открытия — фальстарт, блокировка на пару секунд.
6. Ведущий жмёт «Верно» или «Неверно». Если время ответа вышло, ответ
   засчитывается неверным автоматически.
7. После неверного ответа кнопка открывается остальным на остаток времени.

Всё время игры ведущий может поправить счёт, передать право хода,
поставить паузу, снять вопрос, добавить времени и отменить последнее
действие.

## Структура

```
shared/   типы пака, состояния комнаты и сокет-событий
server/   игровая логика, комнаты, хранилище, импорт паков
client/   React-интерфейсы ведущего, игрока, табло и редактора
data/     паки, автосохранения комнат, история игр
uploads/  медиа вопросов
docs/     дизайн-документ и планы реализации
```
