# Свояк

Своя игра для домашней компании: ведущий за ноутбуком, игроки — с телефонов.

> Проект в разработке. Готовы этапы 0–1: каркас монорепо, типы и демо-пак.

## Запуск

```bash
npm install
npm run build:packs   # разложить демо-паки в data/packs
npm run dev           # сервер :3001 и клиент :5173
```

При старте сервер печатает в консоль ссылку для игроков и QR-код —
наведите на него камеру телефона в той же Wi-Fi сети.

| Экран        | Адрес                        |
| ------------ | ---------------------------- |
| Ведущий      | `http://localhost:5173/host` |
| Игрок        | `http://<ваш-IP>:5173/join`  |
| Общий экран  | `http://localhost:5173/board`|
| Редактор     | `http://localhost:5173/editor` |

## Полезные команды

```bash
npm test        # тесты игровой логики
npm run typecheck
```

## Структура

```
shared/   типы пака, состояния комнаты и сокет-событий
server/   игровая логика, комнаты, хранилище, импорт паков
client/   React-интерфейсы ведущего, игрока, табло и редактора
data/     паки, автосохранения комнат, история игр
uploads/  медиа вопросов
docs/     дизайн-документ и планы реализации
```
