# Свояк: игровой цикл (этап 3) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сыграть настоящую партию обычными вопросами: табло, выбор клетки, честная кнопка с фальстартом, судейство, счёт, переход хода и смена раундов.

**Architecture:** Всё новое поведение — ветки того же чистого редьюсера. Таймеры заводятся эффектом `setTimer`, чьё истечение возвращается в редьюсер действием `TIMER_EXPIRED`. Победителя кнопки определяет сервер по скорректированной на пинг метке, собрав все нажатия за окно `buzzGraceMs`.

**Tech Stack:** Node 24, Socket.IO 4, Vitest 5, React 19, WebAudio.

**Spec:** `docs/superpowers/specs/2026-09-08-svoyak-design.md`

## Global Constraints

- Правильный ответ уходит игрокам только после `answerRevealed` — тест проекции уже стоит на страже.
- Кнопка честная: победитель — минимальная скорректированная метка, а не первый пакет.
- Метка клиента валидируется: не из будущего и не старше правдоподобного RTT.
- Штраф за неверный ответ и уход в минус — по настройкам комнаты.
- Клетка помечается сыгранной в момент открытия вопроса, а не в конце.

## Проверка человеком после этапа

1. Ведущий начинает игру, выбирает клетку — вопрос виден всем, ответ только ведущему.
2. Кнопка открывается после чтения; нажатие до этого блокирует игрока на пару секунд.
3. Двое жмут почти одновременно — выигрывает тот, кто раньше, а не тот, у кого лучше связь.
4. «Верно» — плюс к счёту и право хода; «Неверно» — минус и кнопка снова открыта остальным.
5. Раунд заканчивается, ведущий переходит к следующему.
