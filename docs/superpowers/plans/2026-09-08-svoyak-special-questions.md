# Свояк: спецвопросы (этап 5) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Кот в мешке и вопрос-аукцион играются по классическим правилам: оба идут без кнопки, отвечает один игрок, счёт и право хода считаются так же, как в обычных вопросах.

**Architecture:** Тип вопроса разветвляет только открытие: `PICK_QUESTION` вместо фазы чтения уводит в `cat_transfer` или `auction_bidding`. Дальше обе ветки сходятся в общий `judge()` — у активного вопроса выставлен `soloPlayerId`, поэтому вердикт считает счёт и передаёт право хода тем же кодом, что и для обычного вопроса.

**Tech Stack:** Node 24, Vitest 5, React 19.

**Spec:** `docs/superpowers/specs/2026-09-08-svoyak-design.md`

## Global Constraints

- У спецвопросов кнопки нет вовсе: нажатие в этих фазах игнорируется.
- Неверный ответ на спецвопрос не открывает кнопку остальным — вопрос сразу раскрывается.
- Ставка не может превышать счёт игрока; «ва-банк» — это весь счёт.
- Аукцион всегда завершается: пас необратим, а начальную ставку по номиналу делает открывший.

### Task 2: Аукцион

**Files:**
- Create: `server/src/engine/auction.ts`
- Modify: `server/src/engine/reducer.ts`
- Test: `server/src/engine/auction.test.ts`

**Interfaces:**
- Действие `BID { playerId: string; amount: number | 'all-in' | 'pass'; at: number }`.
- `nextBidder(state): string | null` — следующий по кругу, кто ещё торгуется.

Правила: торги открывает ставка номинала от игрока с правом хода (она ставится
автоматически), дальше по кругу можно поднять минимум на шаг или спасовать. Пас
необратим. Когда все, кроме лидера, спасовали, лидер играет вопрос один.

- [ ] **Step 1: Тесты**

```ts
it('аукцион начинается со ставки номинала от открывшего');
it('поднять можно минимум на шаг');
it('ставка выше своего счёта отклоняется');
it('ва-банк ставит весь счёт');
it('пас необратим и убирает игрока из торгов');
it('игрок, которому нечем перебить, пропускается автоматически');
it('когда все спасовали, играет лидер по своей ставке');
it('победитель отвечает один, кнопка не работает');
it('верный ответ начисляет ставку, а не номинал');
it('неверный ответ снимает ставку и раскрывает ответ');
```

- [ ] **Step 2: Падают** → **Step 3: Реализовать** → **Step 4: Зелёные**
